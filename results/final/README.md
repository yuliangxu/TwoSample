# Final results

This export contains the completed BATTS 0.3.0 pooled-data case study: all eight
comparison tables, 24-fit validation record, held-out null summaries, seven
figures and plotting tables, and the ten-page report. Model order is
ICFM, DT, D, MBGAN.

`input_manifest.json` records the immutable run inputs and source snapshots.
The public counterparts are `../../data/` and `../../scripts/`; packaging
verified those bytes against every recorded hash. The complete runtime copies,
fit RDS files, posterior draws and PCoA caches are regenerated by the root
README commands. Those runtime-only artifacts are not duplicated in this export.

For a quick redraw, run `Rscript scripts/recreate_all_case_study_figures.R`
from the repository root. To rebuild the report, run the complete refit pipeline
first; the report builder requires its verified runtime snapshot and completion
record. `COMPLETE` here records validation of the exported final run.
